# ✏️ 快乐小书法家 · 儿童网页版趣味练字 App

专为少儿启蒙、幼小衔接及小学低年级儿童设计的**网页版互动练字与书法练习应用**。  
支持电脑鼠标、平板触屏（iPad / Android 平板）、触控笔记本等多种设备，提供真实的书法笔触手写体验。

---

## 🌟 核心特色功能

### 1. ✍️ 真实书法触感手写板 (双层 Canvas 架构)
- **多种仿真笔刷**：
  - **毛笔 (🖌️)**：支持起笔、行笔、收笔的动态粗细变化（根据书写速度与压感智能调整，运笔更逼真）。
  - **硬笔 (✏️)**：线条均匀工整，适合练习日常规范字。
  - **彩笔 (🖍️)**：柔和半透明马克笔笔触，增加练字趣味。
  - **橡皮擦 (🧹)**：精确擦除笔迹，不损伤底部的练习格线与描红字样。
- **经典书法练习格切换**：
  - **米字格**（标准八向对角辅助线）
  - **田字格**（四象限基础格）
  - **回宫格**（内外方框间架结构格）
  - **九宫格**（三乘三精准定位格）
  - **空白格**（脱离参考线的自由书写）
- **可调节描红底模**：
  - 一键开启/关闭描红字底模。
  - 自由调节描红字浓度（10% ~ 75%），循序渐进帮助孩子从“跟着描”过渡到“自己写”。
- **操作辅助**：
  - 支持 **撤销（Undo）**、**清空画板（Clear）**。
  - 画笔粗细滑动条调节、多款童趣色彩选择（墨黑、朱红、宝石蓝、翠竹绿、金黄、梦幻紫）。

---

### 2. 📖 智能笔顺演示与闯关跟写 (HanziWriter)
- **标准笔顺动画演示**：
  - 动态演示汉字的标准起笔与书写顺序。
  - 支持 **0.6x 慢速**、**1.0x 正常**、**1.5x 快速** 播放调节。
- **互动跟写闯关模式 (Quiz Mode)**：
  - 孩子直接在屏幕方框中按笔顺书写。
  - 实时检测笔画方向与顺序：写对时播放清脆悦耳提示音；写错时温柔提醒并给出闪烁引导，零挫败感。

---

### 3. 🔊 看图识字趣味插画、拼音与朗读
- **每字专属【看图识字】趣味插画**：在主页面大字旁配有色彩鲜明、生动童趣的插画徽章卡（涵盖292个汉字），点击插画即可触发欢快微动效并伴随语音朗读。
- 标配清晰拼音与声调标注、部首与笔画数统计。
- **大字紧跟常用组词**：在汉字卡片顶部紧随当前字呈现常用组词标签（如“一” -> 一个、一天、第一），点击词组即可朗读。
- 内置 **普通话标准发音朗读**（基于 Web Speech API），点击小喇叭即可朗读汉字标准发音。
- 配备童趣经典例句拓展。

### 5. 🎯 智能写字评分与笔画正误检测（全新升级）
- **笔画数与运笔方向精准检测 (35分)**：
  - 自动对比汉字标准笔画数（如标准 4 笔，实际写了 3 笔或 5 笔会精准指出“多了一笔”或“少了一笔”）。
  - 通过余弦相似度分析起笔与落笔走向，检测倒插笔（如横倒写、竖从下往上写会弹出贴心提醒）。
- **间架结构与重心居中诊断 (35分)**：
  - 自动计算笔画像素包围盒与视觉重心，检测字形是否偏左、偏右、偏上或偏下。
  - 判断字形占格大小比例（过小会提示“放开手脚舒展笔画”，过大会提示“注意收拢外围笔锋”）。
- **字形饱满度与工整度分析 (30分)**：
  - 与标准楷体模型进行逐像素重合度与膨胀容差匹配，分析笔画粗细完整性与多余涂抹。
- **全方位测评报告卡**：
  - 生成大号综合分（0~100分）、称号评级（【甲上 · 妙笔生花】、【优等 · 书写新星】等）与三维进度条。
  - 呈现“名师智能点拨”，给出有针对性、温和鼓励的改进行动建议。

### 6. 🏆 激励体系与字帖打印
- **金星星与已掌握字数**：
  - 每次完成笔顺闯关或完成书写，自动奖励金星并记录已练汉字，进度持久化保存在浏览器本地（`localStorage`）。
- **动感五彩纸屑 (Confetti)**：
  - 闯关成功后爆开展现礼花，激发学习动力。
- **纯原生 Web Audio 趣味音效**：
  - 按钮水滴泡泡声、书写沙沙声、正确音、星星光芒音、胜利号角乐，无网络依赖，毫秒级响应。
- **打印纸质田字格字帖 (🖨️)**：
  - 点击“打印纸质字帖”，自动排版生成符合小学标准的 A4 练习字帖（包含笔画说明、描红行、独立书写行），即刻连接打印机使用。

---

### 7. 📱 单页面零滚动沉浸式自适应设计 (Single-Page Zero-Scroll)
- **整屏一体呈现，无页面滚动**：页面锁定在 `100dvh` 视口高度内，完全杜绝整体页面的纵向滚动，防止孩子在 iPad 或触屏写字时误触拖动页面。
- **仅汉字选择行可滚动**：分类栏与汉字卡片行采用横向平滑轮播（支持手势左右滑动选字），当前选中的汉字自动平滑居中。
- **双板动态等比自适应**：笔顺演示区与书法手写板采用弹性 1:1 动态正方形比例，根据 iPad 横竖屏与各类显示器窗口大小智能缩放，并配备 `ResizeObserver` 保证高清重绘不失真。
- **页面学习进度记忆**：自动记忆孩子上次完成或练习的汉字与分类标签，下次打开应用时直接精准恢复到该汉字，并平滑定位居中，无需每次重新翻找。

## 🚀 如何快速启动与使用

### 方法 1：一键双击运行（推荐）
在项目目录下双击 **`start.bat`** 即可自动打开浏览器运行。

### 方法 2：直接打开文件
直接在文件资源管理器中双击 **`index.html`**，用任意现代浏览器（Chrome、Edge、Safari、Firefox 等）打开即可使用。

### 方法 3：通过本地服务运行
在终端中进入该目录运行：
```bash
python -m http.server 8080
```
然后在浏览器中访问：`http://localhost:8080`
